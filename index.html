ClipFarm

ClipFarm is a personal desktop tool for scheduling and publishing short vertical videos (YouTube Shorts) to YouTube channels owned by its user.

What it does

  • Keeps a local library of short video clips on the user's own computer.
  • Lets the user connect their own YouTube channels via Google sign-in (OAuth).
  • Uploads clips to the connected channels at times chosen by the user, using the official YouTube Data API.

ClipFarm runs locally on the user's computer. It has no server and no user database.
